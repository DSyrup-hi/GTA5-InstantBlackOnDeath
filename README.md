
# Instant Blackout on Death (GTA V)

A custom C# script for ScriptHookVDotNet v3 that replaces GTA V's default "Wasted" screen with an immediate blackout.

## Features
* Instant 0ms screen to black upon player death.
* Suppresses default "Wasted" scaleform overlay and post-processing filters.


## Requirements
* [Script Hook V](http://www.dev-c.com/gtav/scripthookv/)
* [ScriptHookVDotNet v3.0+](https://github.com/scripthookvdotnet/scripthookvdotnet/releases)

## Installation
1. Download the latest `.zip` release from the **Releases** section.
2. Place `InstantBlackOnDeath.cs` into your GTA V `scripts` folder (`Grand Theft Auto V\scripts\`).
